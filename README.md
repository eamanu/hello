## Commands to execute

```bash
$ curl -fsSL https://dl.dagger.io/dagger/install.sh | DAGGER_VERSION=1.0.0-beta.24 BIN_DIR=$HOME/.local/bin sh

$ dagger version
$ dagger init
$ dagger module install github.com/dagger/python-sdk
$ dagger api functions
$ dagger api call <module> <function>
```
